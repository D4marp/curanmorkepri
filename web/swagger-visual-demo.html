🚔 CURANMOR AI - API Documentation

Version: 1.0.0 Total Endpoints: 46+ Base URL: http://localhost:8080/api/v1

Database Curanmor Online — Ditreskrimum Polda Kepulauan Riau

Deskripsi: API untuk dashboard web (input & pencarian data) dan integrasi chatbot WhatsApp AI. Seluruh response menggunakan amplop standar { success, data, error, meta }.

Autentikasi: JWT (cookieAuth) | Bearer Token | API Key (X-API-Key)
